## Actor Options

This section lists the options defined in the IHE Medication Overview (MEOW) Profile. Options are capabilities, beyond the base requirements of an actor, that an implementation may choose to support.

The set of actor options is being developed. A candidate option under discussion is an **On-Demand Document Option**, in which a Medication Overview Repository generates the medication overview on demand rather than serving a pre-built document.

Actor options will be specified in a future version of this Implementation Guide.
