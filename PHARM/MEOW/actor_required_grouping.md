## Actor Required Grouping

This section describes required and recommended actor groupings for the IHE Medication Overview (MEOW) Profile. This content is preliminary and will be completed in a future version.

An actor from this profile (Column 1) shall be grouped with the corresponding actors listed in Column 2.

| | | |
| :--- | :--- | :--- |
| Medication Overview Repository | ATNA Secure Node or Secure Application; IUA Authorization Server / Resource Server (as applicable) | Security and audit (see[Security Considerations](security_considerations.md)) |
| Medication Overview Consumer | ATNA Secure Node or Secure Application; IUA Authorization Client (as applicable) | Security and audit (see[Security Considerations](security_considerations.md)) |
| Medication Overview Creator | ATNA Secure Node or Secure Application | Security and audit (see[Security Considerations](security_considerations.md)) |

The grouping with MPD actors is described in [Cross Profile Considerations](cross_profile_considerations.md).
